# Text Style Override

웹페이지 텍스트 가독성을 높이기 위한 유저스크립트입니다.

## 기능

- `body`와 폼 요소(`button`, `input`, `select`, `textarea`)에 `letter-spacing` 적용
- 같은 범위에 `-webkit-text-stroke-width` 적용
- 최상위 페이지에서만 동작 (iframe 제외)

## 설치

사용 중인 유저스크립트 매니저에서 아래 Raw 링크로 설치합니다.

```
https://raw.githubusercontent.com/ppodori/my-userscripts/main/text-style-override.user.js
```
